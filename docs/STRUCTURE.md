# FX Vault - Repository structure

Current state after the foundation integration. The planned full tree is in `tasks/todo.md` §3.

```
FXVault/
├── project.yml                      # XcodeGen spec: source of truth for the Xcode project
├── .xcodegen-version                # line 1: XcodeGen version; line 2: sha256 of its release zip
├── FXVault.xcodeproj/               # generated by `xcodegen generate`, committed (CI drift check)
├── Config/
│   ├── Base.xcconfig                # app signing defaults: ad-hoc, hardened runtime
│   ├── Signed.xcconfig              # Developer ID signing (team, profile, signed entitlements)
│   ├── Tests.xcconfig               # AppTests signing (no entitlements, no profile)
│   ├── Local.xcconfig.example       # copy to Local.xcconfig (gitignored) to build signed
│   ├── Info.plist                   # generated from project.yml `info:`
│   ├── FXVault.entitlements         # ad-hoc: app-sandbox = false
│   └── FXVault-Signed.entitlements  # + keychain-access-groups
├── App/
│   ├── FXVaultApp.swift             # @main: main Window + Settings scene
│   ├── AppDelegate.swift
│   ├── AppContainer.swift           # composition root (live / preview / test)
│   ├── AppViewModel.swift           # VaultPhase
│   ├── Screens/Root/RootScreen.swift
│   ├── Helpers/Theme/               # Theme, Colors, Typography, Spacing, Radius, Durations
│   └── Resources/                   # Assets.xcassets (AppIcon, semantic colors),
│                                    # Localizable.xcstrings, InfoPlist.xcstrings
├── AppTests/                        # Swift Testing, hosted by the app (runs in .preview mode)
├── Packages/FXVaultKit/
│   ├── Package.swift                # tools 6.1, macOS 14, Swift 6, MemberImportVisibility
│   ├── Package.resolved             # committed: GRDB.swift 7.11.1, swift-sodium 0.11.0
│   ├── Sources/
│   │   ├── VaultCore/               # Identifiers, SecretBytes, Clock (VaultClock), Limits, Timeouts
│   │   │   ├── Models/              # Account, Repo, RepoCapability, Environment, ConfigItem,
│   │   │   │                        # ConfigKind, BranchPattern, DeploymentBranchPolicy
│   │   │   ├── Validation/          # PathSegment, GitHubName, EnvironmentName, RepoName,
│   │   │   │                        # OwnerLogin, GitHubHost, BranchPattern validators,
│   │   │   │                        # DisplayNameSanitizer, ValueNormalizer, ScopeCapacity,
│   │   │   │                        # NameAvailability, UnicodeScalarPolicy
│   │   │   ├── Errors/              # VaultError, ValidationError
│   │   │   └── Extensions/          # Duration+Extension
│   │   ├── VaultCrypto/             # Argon2id (only Clibsodium import), KDFParameters,
│   │   │                            # FieldCipher, AADBuilder, KeyWrap, KeyCheckValue,
│   │   │                            # KeyHierarchy, RecoveryKey, CrockfordBase32,
│   │   │                            # ValueFingerprinter, UnlockedKeys, VaultKeyring,
│   │   │                            # PasswordStrength, CryptoError, CryptoDomain, SecureRandom
│   │   ├── VaultStore/              # (only GRDB import)
│   │   │   ├── Database/            # VaultDatabase, DatabaseFactory, DatabaseTimestamp, StoreConstants
│   │   │   ├── Migrations/          # VaultMigrator, MigrationSQL (v1–v6, frozen)
│   │   │   ├── Records/             # Vault/KeyWrap, Account, Repository, Environment/BranchPattern,
│   │   │   │                        # ConfigItem/ConfigItemState, SyncJournal/ImportedSharePackage
│   │   │   ├── Stores/              # VaultRecord, Account, Repo, Config, SyncJournal, SharePackage
│   │   │   └── Errors/              # StoreError
│   │   ├── GitHubKit/
│   │   │   ├── Process/             # CommandRunning, CommandSpec, StdinPayload, ProcessRunner,
│   │   │   │                        # EmptyWorkingDirectory
│   │   │   ├── Environment/         # ProcessEnvironmentBuilder, ShellEnvironmentResolver
│   │   │   ├── CLI/                 # GHLocator, GHVersion, GHAuthService, GHTokenCache,
│   │   │   │                        # AuthStatusDTO, ScopeChecker
│   │   │   ├── Commands/            # GHCommand (GHOperation, GHArgumentPolicy), GHCommandService,
│   │   │   │                        # GHCommandScheduler(+Extension), GHRepoRef, argv builders
│   │   │   ├── API/                 # GHEnvironmentsAPI, GitHubPath, APIResponseParser, JSONValue
│   │   │   ├── DTOs/                # GHRepoDTO, GHSecretDTO, GHVariableDTO, GHEnvironmentDTO,
│   │   │   │                        # GHBranchPolicyDTO, GHJSONDecoding
│   │   │   ├── Errors/              # GHError, GHStderrClassifier, StderrRedactor
│   │   │   ├── SSH/                 # SSHConfigParser, SSHAliasResolver, SSHAliasValidator
│   │   │   ├── Git/                 # GitService, GitError
│   │   │   ├── Support/             # GHConstants, Data+Extension
│   │   │   └── Testing/             # FakeCommandRunner (tests and previews)
│   │   ├── EnvTools/                # EnvToolsLimits
│   │   │   ├── Parsing/             # DotEnvParser, DotEnvSerializer, DotEnvEntryModel, EnvParseIssue
│   │   │   ├── Keys/                # KeyNormalizer
│   │   │   ├── Credentials/         # CredentialClassifier
│   │   │   ├── Import/              # EnvImportPlanner
│   │   │   ├── Files/               # SecureFileWriter, CloudSyncDetector
│   │   │   ├── Git/                 # GitignoreChecker (+ GitExposureInspector), GitignoreEditor
│   │   │   └── Internal/            # ASCII, PathResolver
│   │   ├── SharingKit/              # ShareError
│   │   │   ├── Model/               # SharePackageModel, SharePackageCoder, SharePackageValidator
│   │   │   ├── File/                # FxVaultHeaderModel, FxVaultFileCodec, KeyDeriving
│   │   │   ├── Passphrase/          # PassphraseGenerator
│   │   │   ├── Nearby/              # NearbyProtocol, NearbyCrypto, NearbyFrame, NearbyHandshake,
│   │   │   │                        # NearbySession, NearbyTransport, NearbyLengthFramer,
│   │   │   │                        # NWNearbyTransport
│   │   │   ├── Import/              # ShareImportPlanner, ShareImportPlanModel
│   │   │   ├── Extensions/          # Data+Extension
│   │   │   └── Resources/           # eff_large_wordlist.txt
│   │   ├── SyncEngine/              # placeholder (SyncEngineModule)
│   │   └── VaultData/               # placeholder (VaultDataModule)
│   └── Tests/<Module>Tests/         # one Swift Testing target per module, each with Fixtures/
│       ├── VaultCryptoTests/Fixtures/kat/        # generate_kat.py + kat_vectors.json
│       ├── SharingKitTests/Fixtures/             # nearby_kat.json, kat/ (crosscheck.py, reference)
│       ├── GitHubKitTests/Fixtures/              # gh/, api/, ssh/, shell/ (sanitized)
│       └── EnvToolsTests/Fixtures/sample.env     # placeholder values only
├── scripts/
│   ├── ci-local.sh                  # runs the blocking CI checks locally
│   ├── lint.sh                      # convention checks (force unwraps, print, imports, ...)
│   ├── check-secrets.sh             # secret scan of files git would publish
│   ├── check-secrets-allowlist.txt  # .env keys whose values are public identifiers
│   ├── make-icon.swift              # draws the AppIcon set
│   ├── release-local.sh             # archive, sign, notarize, staple, DMG, optional publish
│   ├── make-dmg.sh                  # DMG with an Applications link (diskutil, hdiutil fallback)
│   └── bump-cask.sh                 # fills version and sha256 into the Homebrew cask
├── ci/ExportOptions-DeveloperID.plist  # xcodebuild -exportArchive options (Developer ID)
├── Casks/fx-vault.rb                # Homebrew cask template (copied into the tap by bump-cask.sh)
├── .github/
│   ├── workflows/ci.yml             # macos-26 (blocking), xcode-27, gitleaks
│   ├── workflows/release.yml        # ad-hoc DMG; signed + notarized when secrets exist
│   └── actions/setup-toolchain/     # select Xcode + install pinned XcodeGen
├── .gitleaks.toml                   # default rules + allowlist for synthetic test vectors
├── docs/
│   ├── ARCHITECTURE.md              # modules, layers, public APIs
│   ├── STRUCTURE.md                 # this file
│   ├── DATABASE.md                  # migrations, tables, transactions
│   ├── API.md                       # gh / git / ssh command catalog
│   ├── SHARING-PROTOCOL.md          # payload, .fxvault, nearby protocol, merge rules
│   └── RELEASING.md                 # signing, notarization, cask, manual checklist
├── tasks/                           # todo.md (plan), lessons.md
├── README.md, LICENSE, SECURITY.md, CONTRIBUTING.md, THIRD_PARTY_NOTICES.md
└── .gitignore
```

Gitignored and never committed: `.env` (and any `*.env` outside
`Packages/FXVaultKit/Tests/*/Fixtures/`), `.research/`, `Config/Local.xcconfig`, signing material
(`*.p8`, `*.p12`, profiles) and build output (`.build/`, `.build-*/`, `.build-release/`,
`DerivedData/`, `dist/`, `*.dmg`, `.spm/`, `*.xcresult`).
